# v1 首发说明（给官网和社区）

> 10-16 更新：螺壳记忆并进主控、首次运行可选省空间、模型两个下载地址、主控能升级和卸载、安装器文件名改成英文。

luoke-top 2026-10-15 按主人的决定（顶层 [ADR 0017](adr/0017-v1-first-release.md)）写，交给 luoke-community（官网和社区）。这里只写顶层定下的和要对齐的；怎么做由运营规划那边定。

## 首发给用户什么

| | 是什么 | 用户的感知 |
|---|---|---|
| **螺壳邮件助手** | 首发主打之一：整个邮箱分拣、清理、订阅体检和退订、订阅精选、起草回复（只进草稿箱）。支持 Gmail、QQ、163/126、自定义 IMAP | 装好十分钟内看到效果；"邮件不出电脑"最硬 |
| **螺壳输入法** | 首发主打之一：小鹤双拼、全拼，本机模型按前文重排候选（首选准确率约 90%，苹果自带约 79%），联想 | 每天都用、黏性最强，效果偏含蓄 |
| **螺壳记忆** | 装在主控里（10-16 起不再是单独的 app），从主控菜单「记忆…」或各应用里的入口打开：看到螺壳记住了你什么，每条能看依据、能否定、能删 | "它在慢慢了解我，而且我看得见、管得了" |
| **主控** | 随装，菜单栏一个小圆点；管本机所有模型 | 知道 AI 在自己机器上跑、占了多少 |
| **agent「螺壳」** | 不首发，官网写"开发中"（主人 10-17 定，照品牌规范；不写"下一个"）：会主动跟你说"今天 5 封新邮件，我建议这样处理，可以吗"，以后手机上也能收到 | 讲清这件事往哪走 |

品牌：对外以**螺壳实验室**（Luoke Labs）为主，应用是实验室的作品。主控是底座，不当产品卖。不叫"平台""套件"（顶层 CONTEXT）。

跨应用的那个时刻：你打字时常聊的话题，邮件助手的订阅精选会优先挑出来（同一份记忆，顶层 ADR 0015）。

## 用户视角的整体体验

1. **看到**：一句话，大意是"你的 AI，只住在你的 Mac 里"。
2. **下载**：点"邮件助手"，下载到 `install-mail-<版本>.dmg`，里面是"安装邮件助手"（GitHub 附件名不收中文；luoke-core ADR 0002）。打开后由主控接手：先检查这台 Mac 是哪一档、能有什么体验（照实说），列出要下载什么、多大，一屏同意；64 GB 以上的机器可以选「完整」或「省空间」（10-16 定）。模型同时有 ModelScope 和 Hugging Face 两个地址，主控测速选快的。
3. **等待**：模型下载是全程最长的门槛（16 / 32 GB 档约 6 GB 起，128 GB 档更大）。这段时间引导设置邮箱授权码（QQ、163、Gmail 分别手把手），不让人干等。
4. **十分钟内见效**：最近的邮件分好拣，一眼看到"要回的 3 封"；顺手退订从来不看的推送。输入法装好后引导去系统设置添加输入源。
5. **慢慢变懂他**：几天后，记忆页面出现"我注意到你关注……对吗？"，订阅精选越挑越准。
6. **始终放心**：每个改动都能撤销；不打扰；数据不离开电脑；菜单栏能看到 AI 在干什么。
7. **下一站**：agent「螺壳」来了，开始主动跟他说话；再往后手机上也能收到（经用户自己的设备之间端到端加密，顶层 ADR 0013）。

## 各档体验要照实写

Apple 芯片、16 GB 起，推荐 32 GB 以上；**macOS 26.2 以上**（主人 10-15 定，ADR 0017：引擎包里 mlx 的库按 26.2 编，更老的系统上主控首次运行在预检页拦住）。各档实测数据在 luoke-core 的 `docs/experiments/`，具体数字以那边为准：

| 档位 / 芯片 | 邮件助手 | 输入法 | 从打字里学 |
|---|---|---|---|
| 16 GB | 后台分拣只在用户不用电脑时慢慢做（每封约 50 秒）；用户点的同步可以现加载 | 慢芯片上退到小档，仍比苹果自带好 | 不支持 |
| 32 GB | 正常（9B 模型） | 看芯片 | 支持 |
| 64 GB 以上 | 正常（128 GB 档用 gemma-26B） | 看芯片 | 支持 |
| 基础款芯片（含基础款 M4） | — | 小档 | — |
| Pro / Max 芯片 | — | 完整体验 | — |

## 官网可以有的栏目（建议）

- **首页**：一句承诺（本机、私密、越用越懂你），加两个应用、一个下载按钮、一张"它们怎么协作"的图（一份模型、一份记忆）。
- **每个应用一页**：做什么（动图）、上面那张各档体验表、数据存在哪、螺壳读了什么来懂你。内容由各项目提供。
- **我们的承诺**：把顶层 ARCHITECTURE §4 的底线改写成对用户的话：
  - 你的数据不出你的设备，只在你自己的设备之间、端到端加密；
  - 在你的设备上，螺壳会读它需要的一切，好真正懂你；密码、验证码这类凭证不进记忆；
  - 记忆能看、能改、能删；
  - 能撤回的，你确认一次就替你做并告诉你；删除、退订这类永远要你自己点。（顶层 ADR 0013、0016，2026-10-19）
- **实验室**：公开实测和评测，例如"16 GB 上能不能边打字边分拣""为什么 32 GB 档选 9B""评测集怎么定硬性条目"。素材在 luoke-core `docs/experiments/` 和各项目的评测里，挑能公开的。
- **路线图**：agent「螺壳」（开发中）、手机端。
- **下载**：GitHub Releases（v1 不考虑访问不了 GitHub 的用户，luoke-core V1 §4），写明系统要求。
- **常见问题**：要多大内存、下载多大、会不会上传、怎么升级（打开新版安装器即可，数据和模型保留）、怎么卸载（主控菜单「卸载…」：应用的数据默认不删、勾选才删；记忆文件永远保留，可以另选一起忘掉某个应用写的）。

## 社区要对齐的几点（顶层）

- **定位**：实验室驱动、面向本地 AI 爱好者（顶层 CONTEXT："实验室"负责发布、评测和配方，用户社区叫"螺壳社区"）。
- **第一批人**：封闭测试者（20–50 位，覆盖各档、各芯片、各邮箱），就是社区的第一批人。
- **能参与的地方**：
  - 反馈问题；
  - 写输入法引擎（沙盒里跑、用 A2UI 描述设置页，见 luoke-ime 的 `docs/写引擎.md`）；
  - 以后 agent 的工具协议定下来，可以写工具（luoke-agent `docs/工具协议.md`）。
- **透明**：公开评测方法和结果；诊断信息默认不收，只收元数据、由用户决定发不发（底线）。
- **渠道、节奏、内容计划**：由 luoke-community 定。

## 各项目要提供的

| 项目 | 提供什么 |
|---|---|
| luoke-mail | 邮件助手那页：功能、动图素材、各档体验、隐私细节（读什么、存哪、写操作都要用户点）；示例收件箱可以用来做演示 |
| luoke-ime | 输入法那页：功能、准确率实测、各芯片体验、隐私细节（安全输入不记、按应用不记录、暂停、要用户同意才学）；写引擎的入门 |
| luoke-mem | 记忆那页：记什么、怎么看依据、怎么否定和删除、敏感内容怎么处理 |
| luoke-core | 主控和首次运行的说明、各档实测（实验室栏目的主要素材）、系统要求、下载和安装、卸载 |
| luoke-agent | 路线图那页：agent「螺壳」将来是什么样 |
