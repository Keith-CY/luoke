# 本机就是边界：数据不出用户自己的设备，本机组件之间不设隐私限制

2026-10-19，主人决定。和 0014–0017 一起取代归档的 0001–0012（`archive-2026-10-19/`）。

## 决定

1. **边界只有一条：数据不出用户自己的设备。**
   - 工具和模型只在用户的 Mac 上运行。
   - 数据只在用户自己的设备之间流动，并且端到端加密，比如经 Tailscale 连回 Mac 的手机 app。
   - 第三方服务只经手读不了的加密数据，或者不带内容的提醒。
   - 默认不向外发送任何内容；诊断信息由用户自己决定发不发。
2. **本机组件之间不为隐私设限。** 主控、记忆、各工具、agent 都在用户自己的机器上，要读什么就读什么，只要能把事做好：
   - 记忆归纳时读各工具的原始记录和原文，比如邮件正文、打的字；
   - 各工具可以读彼此的记录和理解；
   - agent 可以读全部，也可以把依据原文给用户看。
   不再有"原始记录只读自己写的""敏感类别要按工具授权""只在某个界面显示""要另外同意才读已发送"这类规定。
3. **凭证不当内容存。** 密码、验证码、密钥、令牌、完整的卡号和证件号不存进记忆，要用时走钥匙串或用户的密码管理器，值不经过模型。这是安全问题，不是隐私问题：它们存了对理解用户没用，泄露的损失却最大。
   - **保险箱（luoke-vault，方向，主人 10-19 定）**：凭证的值放在钥匙串里，记忆只记元数据（比如"有一张尾号 1234 的 Visa，在保险箱里"），AI 照样知道你有什么。
     - **取用不用用户每次操作**：钥匙串条目只授权给螺壳自己签名的程序，取用时不弹确认；开机解锁过一次以后，锁屏时也能取。
     - **值直接填进表单，不经过模型**：这是防注入。agent 会读网页和邮件，值一旦进了模型，就可能被一段恶意文字骗着说出去。
     - **花钱照 ADR 0016 永远要用户确认**；有了手机 app 以后，可以在手机上点。
     - 首发不做（agent 不在首发里），先做成 agent 的一部分，别的工具也要用时再独立成项目。
4. **用户随时看得到、改得了、删得掉。** 每条理解都能查到依据；用户可以否定、修改、忘掉。

## 为什么

主人原话："本来 local 受限于模型和算力就已经要差了，隐私上不放开的话，凭啥用你？""现在云端 AI 都上赶着跟用户要 mail full access，我们做 local 的反而要收着来损失体验吗"。

本机 AI 能赢云端的只有一点：用户的全部数据都在自己机器上，可以毫无保留地交给 AI 去理解。在本机内部再层层设限，就是把这个唯一的优势也丢掉。试用期已经看到了代价：记忆只拿到发件人的名字和封数，于是把 Zillow 当成一个"话题"，却不知道主人订的是一个特定邮编的房价提醒。

## 后果

- 归档的 ADR 和各项目文档里，凡是"为了少看数据"而设的限制，一律作废，由各项目在核对时删掉。这包括 ARCHITECTURE §4 原来的"原始记录只给写它的工具"和"敏感内容分三类"里的保护部分，也包括各项目 CLAUDE.md、DESIGN 里由它们带出来的约束。
- 具体要去掉的（详见 `ops/docs/privacy-limits-audit-2026-10-19.md`）：
  - 输入法的记忆记录、邮件助手的「了解你」改成默认开：开始时说明一句，设置里能关。
  - 库里"原始记录只读自己写的""依据只给来源和条数"取消，各工具、agent 都能读全文依据。
  - 敏感类别的按工具授权、只在记忆界面显示取消。"敏感的推断要用户本人说或确认才生效"作为防推错保留，由 luoke-mem 定。
  - 敏感词过滤收窄到真正的凭证：密码、验证码、密钥、令牌、完整卡号和证件号。命中时只遮那一串，不丢整段；"6 位以上数字""出现'账号'二字""出现金额"不再触发。
  - 涉及钱的第三方事实不再一律挡在门外，账户类照常按证据定档。
  - 记录里可以带正文和前文（前文标成第三方）；agent 可以在本机存对话历史和卡片内容。
- 保留的是安全问题，不是隐私问题：
  - 密码框等安全输入时不记；
  - 第三方代码（社区引擎、可替换的组件）跑在沙盒里，碰记忆要另外同意；
  - 本机服务只监听 127.0.0.1 并带令牌；
  - 删除这类不可逆操作只在明确的地方做；
  - 数据不出本机：诊断只含元数据，推送不带内容，手机上不留记忆副本。
- 对外说法改成："你的数据不出你的设备；在你的设备上，螺壳会读它需要的一切，好真正懂你。"

## 修订（2026-10-19）：本机端点的密钥可以自己改、可以不要

主人看了高级用户端点（ADR 0014 修订）的密钥，说："密钥为什么要搞这么复杂还不能自己改？" 改为：
- 密钥用户可以自己填，比如沿用 oMLX 那把；也可以留空，留空就不校验密钥。默认照旧生成一把。
- 挡网页攻击的 Host 校验和拒绝 Origin 照旧保留。
- 留空时设置页照实提示：这台 Mac 上任何程序、任何登录的账户都能用这个端点。上面"本机服务只监听 127.0.0.1 并带令牌"一句，对这个端点改成"默认带令牌，用户可以去掉"。
