## 决定

1. **首发集合**：螺壳邮件助手、螺壳输入法，各有下载入口；主控和记忆随第一个应用装上，记忆打在主控里。agent「螺壳」不在首发里，跟着 v1.x 出。
2. **节奏**：
   - 主人本机试用到 10-28；
   - 封闭测试 20–50 人，覆盖 16 / 32 / 64 GB 以上、基础款和 Pro / Max 芯片，邮箱覆盖 QQ、163、Gmail；
   - 修完再公开。
   - beta1：10-24 只修不加，10-26 20:00 截版，10-27 出版，10-29 发第一批，11-02 第二批。
3. **硬件和系统**：Apple 芯片、16 GB 起，推荐 32 GB 以上，macOS 26.2 以上。首次运行按内存档和芯片照实说能有什么体验；每个任务在哪一档开，按评测定（连过 3 遍才开，失败一遍就关）。
4. **品牌**：对外以「螺壳实验室」（Luoke Labs）为主；各应用叫螺壳邮件助手、螺壳输入法、螺壳记忆，以后还有 agent「螺壳」。主控是底座，不当产品卖。
5. **仓库和发布**：
   - 代码放 GitHub 组织 luokelabs，先全部私有；
   - 安装包放公开的 luoke-releases，预发布版公开可见、只是不推广；
   - 每天 20:00 截一个内部版（`internal-MMDD`），不用每次问；beta 和公开发布每次先问主人；
   - 开源仓库署名"螺壳实验室 Luoke Labs"。
6. **官网和社区**（10-19 改定）：
   - 官网前端、对外文案、招募（发帖、建报名表）归团队的 Jason（GitHub @stwith），在 luokelabs/luoke-brand 的 `site/` 先改，确认后同步到 luoke-community/site。主人原话："这些都由 Jason 处理，除非他明确提出需要我参与"。
   - luoke-community 管事实出处（数字和说法对得上各项目）、测试说明、问卷、测试者名单建议和社区；要改官网就给 luoke-brand 提 issue。
