记忆接口与表结构

Python 包 luoke_mem（仅标准库，3.9+）。工具只需 __init__、memory、sensitive 三个模块；运行在主控里的配件应使用 GET /tasks 返回的 luoke_mem.path。

打开

  • Memory(path=None, tool="luoke")：工具使用。默认路径 $LUOKE_HOME/mem.db，未设置时为 ~/.luoke/mem.db。文件 0600，目录 0700；记忆文件或其 -wal、-shm、-journal 是符号链接时拒绝打开。文件不存在时创建（0600）；只看不改的入口（命令行 sources、forget-tool、learn）不创建。
  • WholeMemory(path=None)：整份记忆，供记忆自己的界面、命令行和归纳任务使用；打开时执行重新定档（只降不升）、以前的事、相近话题合并。第一次定档前把整份记忆复制为 mem.db.before-0.18，14 天后或有内容被忘掉时删除。
  • 文件 schema 比库新得多（千位不同）时抛 TooNew。

工具接口

记录

方法说明
record(speaker, kind, text, *, topic, data, ref, happened_at, sensitive)写一条记录；正文和 data 中的字符串先遮去凭证
redate(rid, happened_at)修正本工具一条记录的发生时间
records(*, tool="", topic, kind, speaker, ref, since, limit)tool="" 为本工具，传工具名读该工具，None 读全部
forget_records(*, topics, since, until, match, keep_cited)删除本工具的部分记录，只依赖这些记录的理解一并删除
forget_tool(tool=None, *, dry_run)删除本工具写入的全部内容；用户说过的话和表过态的理解转到记忆名下保留

理解

方法说明
state(kind, text, …)用户亲口说的，直接为"确定"
propose(kind, text, cites, …)推测；按定档规则可能直接生效
conclude(kind, text, cites, …)由用户自己的记录得出；依据须全部来自用户，按定档规则为比较确定或猜测
confirm(nid) / reject(nid) / was(nid) / later(nid) / revise(nid, text)用户的决定：确认、否定、以前是、以后再说、改写
notes(kinds, status, tool, confidence)默认只返回生效的（比较确定和确定）；每条带 confidence、data、auto、fresh
note(nid)一条理解及其全部依据（含原文）
recent(since, limit)未经用户表态而直接生效的推断
context(kinds, limit=600)按类别拼成供模型使用的一段文字
forget(nid)删除理解、其历史版本及只被它引用的记录

想问的和建议

方法说明
asks(status=["open"], *, tool)未过期的问题和建议；tool 筛出与某工具相关的
reply(aid, choice, text=None)交回用户的回答：关于某条理解的问题 yes / no / past / revise / later（later 把问题记为 later，7 天后由反刍重新提出）；自由问题只接受 answer；建议 useful（关于习惯的建议同时确认该习惯）/ useless / never；其他组合抛 ValueError

工具函数

mask_secrets(text)（遮去密码、验证码、密钥、通过 Luhn 校验的卡号、证件号）、find_secrets、sensitive_kinds(text)（健康、法律、宗教政治）、confidence(note)、default_path()。

表结构（schema 7）

表列
recordsid、tool、speaker、kind、topic、text、data_json、ref、happened_at、recorded_at、sensitive
notesid、tool、kind、text、origin（user / inferred）、status、superseded_by、valid_from、valid_to、formed_at、decided_at、why、topic、sensitive、data_json
cites(note_id, record_id)
asksid、tool、kind（question / suggestion）、text、why、about_note、about_kind、urgency、answer（JSON）、status、created_at、expires_at、decided_at、answer_record、sensitive、evidence、rank、action（JSON）、key
candidatesid、kind、text、record_ids、first_seen、last_seen（归纳中积累的候选）
learningname、value：归纳进度（typing.last_id / last_at / last_run、topics.last_id / last_at / last_run / pending / version）、每次结果（typing.last_outcome、topics.last_outcome、rumination.last）、以前的事唤回次数（past.revived.<kind>）、一次性修复标记

升级只加不改：新表、可空的新列、新索引。版本存于 PRAGMA user_version。

命令行

命令说明
python -m luoke_mem [--path P] sources各工具写入的条数
forget-tool <tool> [--dry-run]忘掉某工具写入的内容；luoke-mem 被拒绝（说明原因，退出码 1）
ui [--open] [--note N] [--view recent]打印界面地址
app [--note N] [--view recent]在浏览器中打开界面（luoke://memory 的入口）
learn [--force] [--again] [--hub SOCK]运行一次归纳；--force 有新记录就跑；--again 从头重新归纳（打字记下的不重复，话题线用户没表态的话题重来）；已有一个在跑时直接返回

界面

独立进程，监听 127.0.0.1 随机端口；页面令牌在 ?t=，接口令牌在 X-Luoke-Token；校验 Host 和 Origin；600 秒无请求退出。路由：/api/ping、/api/summary、/api/overview、/api/records、/api/notes、/api/note、/api/recent；修改用 POST /api/change（confirm、reject、forget、revise；修改文字 ≤ 200 字，拒绝凭证）、/api/forget-tool（拒绝 luoke-mem）、/api/forget-all（需输入「清空」）。/api/grants、/api/grant 为遗留接口，不再影响读取。界面状态（pid、端口、令牌）存于 mem.db-ui.json（0600）。
