术语含义
主控（luoke-core）本机推理入口和安装器
配件由主控安装和管理的应用：邮件助手、输入法、agent，以及规划中的深度搜索
深度搜索（luoke-search）本机文件和照片图库的索引与检索工具，没有界面，经 agent 的 MCP 工具和命令行使用
任务配件向主控请求推理的单位，形如 luoke-mail.triage
底座每档用于生成任务的主模型
专用模型只服务某类任务的小模型，如打分、嵌入
硬件档按内存划分的 16 / 32 / 128 三档
配方描述各档模型、任务参数和允许接入版本的 recipe.json
支持台账出版时记录每个任务在每档开或关的依据，发布后的复测结果也写在这里
冒烟检查引擎启动后的实测，得出本机速度
空闲任务配件登记、由主控在安静时刻启动的命令
安静时刻距最近一次用户在等的请求满 5 分钟
用户在等用户正在等待结果的请求等级
记录写入记忆的"发生了什么"
理解记忆从记录形成的关于用户的认识
把握程度理解的三档：猜测、比较确定、确定
以前的事会变、且长期没有新依据的理解
反刍记忆在空闲时整理理解、产出提问和建议的过程
处理习惯"某发件人的某类邮件通常这样处理"的理解
今日处理邮件助手中复查当天全部处理结果的页面
螺壳自己的邮箱用户为 agent 开设、由邮件助手全自动处理的邮箱
能力工具声明给 agent 的可报事项和可执行动作
个人化组件输入法中负责写记忆、转发打分和联想的组件
引擎（输入法）沙盒中给出候选的子进程，如小鹤双拼
本机放行在内部版或本机版主控上允许尚未进入配方的配件新版本接入
高级用户端点主控提供给外部工具的 OpenAI 兼容接口
