配件清单与配方

配件清单 luoke-accessory.json

位于配件 .app 的 Contents/Resources/。主控只加载 contract == 1 且有 accessory、bundle_id 的清单。

字段说明
contract、accessory、bundle_id必填
name、version显示名和版本；升级只换比清单旧的版本（按数字比较，不降级）
typeapp（装在 ~/Applications）、input-method（装在 ~/Library/Input Methods）、component；只有 app 可常驻
entry交给自带 Python 的入口参数
resident是否常驻（配件也可经 PUT /accessory/resident 声明）
memory是否读写记忆；决定卸载时能否"一起忘掉"、首次运行是否需要记忆
tasks需要主控提供的任务（名、kind）
jobs空闲任务：name、command（可用占位符 {memory}、{tool}）、min_interval_minutes（默认 120）、allow_battery（默认否）、timeout_minutes（默认 30）
capabilities给 agent 的能力声明，主控原样转交（规格见 agent 的工具协议）
data卸载时可删除的数据路径，只接受与配件自身标识绑定的形式
commandsuninstall（删除数据前运行）、forget-tool（从记忆中忘掉本工具写入的内容）
icon、ui_element打包用

打包布局

<名字>.app/Contents/MacOS/<配件标识>             启动器
<名字>.app/Contents/Resources/luoke-accessory.json
<名字>.app/Contents/Resources/python/bin/python3   钉住版本的 python-build-standalone
<名字>.app/Contents/Resources/python/lib/python3.X/site-packages/<包>

由 luoke-core/tools/package_python_app.py 生成。

校验

  • 调用时：版本在配方 verified 中，或在内部版、本机版主控上被本机放行（tools/local_allow.py，只放行配方中已有配件的新版本）；或是本机 verified-history.json 中记录过的已安装版本（只限记录中的任务）。
  • 安装时：代码签名、Team ID NJQ5W3T9K5、bundle id 与清单一致、公证票据有效。
  • 回滚时：旧版同样核签名、Team ID、bundle id、公证票据，不运行它，版本从其清单读取。

配方 recipe.json

字段说明
tiers.<档>min_gb、max_gb、guard_gb（引擎内存上限）、base_resident（底座是否常驻）、idle_unload_secs
models.<名>dir、kind（base / special）、wired_gb、size_gb、速度、vector_space（嵌入）等
assignment.<档>{base, special: {<任务>: <模型>}}
engine引擎版本和位置
tasks.<名>accessory、kind（generate / score / predict / embed）、params（"*" 加按档覆盖）、base_params（采样）、latency_ms、tiers（开启的档）
verified.<配件>versions（允许接入的版本）和各任务的评测证据
evidence评测记录：配件、版本、任务、模型、档、结论、评测集和证据的 sha256
expectations首次运行按档和芯片向用户说明的体验

任务参数

kind参数（默认）
generateitem_tokens（200）、fixed_tokens、batch、max_chars、think；配件自定义的参数原样转交（如 sender_verdict）
scorebatch（16）、max_chars（2000）、prefix_snapshots（16）、probe
predictk（8）、n（6）、max_tokens、max_chars、probe
embedbatch（32）、max_tokens（2048）、max_chars（32000）、max_total_chars（320000）；多模态另有图片、音频的批量和大小限制

发布清单 release.json

{contract, release, built_at, items: {<名>: {kind: model | engine | accessory | hub, version, dir, files: [{path, size, sha256}], urls, bundle_id?, type?, installer?, min_macos?}}}。模型有 ModelScope 和 Hugging Face 两个镜像，安装包放在 GitHub 的 luokelabs/luoke-releases。主控的"检查更新"从 items.hub 取 DMG。
