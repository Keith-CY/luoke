输入法

macOS 输入法。壳负责按键、组字、候选窗和上屏；候选全部由沙盒里的引擎子进程给出。个人化组件把上屏写入记忆，并把打分和联想请求转给主控。

仓库 luoke-ime · 版本 0.1.19 · bundle id ai.luoke.inputmethod.Luoke

结构

部分实现职责
壳Swift：LuokeShell（平台无关的状态机和引擎宿主）+ LuokeIME（InputMethodKit 外壳）；另有共用状态机的命令行版按键、组字、候选窗、上屏、沙盒、转问
打字引擎自带小鹤双拼 xiaohe、全拼 quanpin（苹果转换引擎和 RIME 出候选）出候选，经个人化组件请求打分后重排。小鹤、全拼有评测用的选项 pause（毫秒，默认 0）和 pause_when（slow / always）：键后停顿够久才重排；默认关。
个人化组件engines/personal（Python，仅标准库），运行在主控自带的 Python 上写入记忆；把打分和联想转给主控

进程模型

  • 壳由系统拉起，不进程序坞；用户自己打开 LuokeIME.app 时也作为输入法服务运行。每个输入框一个 Session；全进程一个 EngineManager，主线程每秒轮询配置和引擎状态。带不认识的参数时打印用法退出。只运行一份：父进程不是 launchd 时直接退出；用 $TMPDIR/ai.luoke.inputmethod.Luoke.lock 文件锁占位（最多等 3 秒），已有一份时请在跑的那份按需弹添加引导，自己退出。
  • 换版：每 5 秒读一次磁盘上包里的 build 号，和启动时不同且新包的可执行文件在时，等所有输入框空闲（不在组字、没挂着逗号、不在快捷键会话、联想没打开）且 3 秒没有按键，收尾退出，1 秒后用 open -g 从原路径拉起新版。
  • 引擎以 posix_spawn 在独立进程组中启动，命令为 /usr/bin/sandbox-exec -p <模板> …，工作目录是引擎文件夹。run[0] 为 luoke-python 时使用螺壳（主控）包内的 Python：依次找 /Applications、~/Applications 下的 螺壳.app、螺壳主控.app，核对 bundle id ai.luoke.core，不问 LaunchServices；都没有时用 PATH 里的 python3；参数前加 -B -E -s -u。自带引擎用固定 PATH；第三方引擎第一次启动时才解析登录 shell 的 PATH（最多 3 秒）。
  • 通信：标准输入输出上每行一个 JSON，第一条必定是 hello；写入走每个引擎自己的串行队列。
  • 停止：关闭 stdin，1 秒后对整个进程组 SIGKILL。
  • 崩溃与卡死：一次询问 1 秒没有答复视为卡死并杀掉；60 秒内崩溃 3 次则停用该引擎。
  • 退出：收到 SIGTERM、SIGINT、SIGHUP、正常结束或换版让位时，结束系统日志订阅，并向主控发 POST /accessory/exiting（1 秒超时）。
  • 重启条件：设置文件变化、用户引擎目录变化、非自带引擎的文件变化、options.json 变化、主控 Python 被替换（每 10 秒检查）。

引擎协议

版本 1。完整规格见 luoke-ime/docs/引擎协议.md。

方向消息
壳 → 引擎hello、query（输入、前文、应用）、committed、deleted、forget、forget_all、unforget、start / stop / cancel（快捷键引擎）、ask、reply
引擎 → 壳answer（候选、more、autocommit）、show、commit、end、ask、reply

引擎说明 engine.json

  • 必填 protocol（=1）、name、kind、run；打字引擎需 input_keys，快捷键引擎需 hotkey。
  • 可选 context（0–2000 字前文）、app、feedback、forget_all、asks（⊆ personal、hub）、options、punctuation。
  • permissions：network（none / local / any）、write（≤ 16 个路径）、local_ports、microphone、camera、screen、gpu、memory（只有个人化组件能声明）。
  • 声明 asks: personal 的引擎只能 network: none，或 local 并用 local_ports 限定端口；个人化组件不能联网，不能声明麦克风、摄像头、屏幕，asks 里只能有 hub。

第三方引擎

  • 声明联网、GPU 或写权限的第三方引擎不能启用。
  • 启用需要用户确认，确认记录绑定引擎说明的指纹（关键字段的 SHA-256），说明变化后需重新确认。
  • 不会被自动选中；与自带引擎同名时使用独立的数据目录 <id>.third-party。
  • 引擎只能向个人化组件请求 score 和 ping；predict 只有壳能发起。

候选流程

  1. 按键经 MacKeys.translate 翻译，进入会话；空闲时按下输入键会读取前文（安全输入时不读）。
  2. 壳向打字引擎发 query；只采用最新一次询问的答复，50 ms 内收到的最后一份直接显示。
  3. 打字引擎先给快答复（改选过的词、苹果候选、RIME 补充），能重排时标 more；再经壳把 score 转给个人化组件，个人化组件转主控 luoke-ime.rerank，最多等 0.7 秒。
  4. 逐词重排：模型得分须比苹果整句首选高出阈值（自然对数 3）才替换；换掉首选时补发答复，界面让新首选淡入。
  5. 空格、数字、标点等收尾键在还没有任何答复时先等第一份答复，最多 1 秒（判定卡死）；卡死则按原始字母上屏，数字原样交给应用。之后最多再为补发等 150 ms。回车、Esc 不等。上屏后，空格或数字选中的会接着请求联想。
  • 拼音显示位置：默认显示在输入框里（显示串），可按全局或应用改成显示在候选窗里。
  • 「-」：第一页按「-」（翻页键为 - 和 = 时），已选部分和拼音串照原样字母上屏，再交给应用一个「-」（可打 luoke-ime、gpt-4）；不在第一页照旧翻页。
  • 数字后的标点：数字后按逗号先挂在光标处，接数字上屏半角「,」，接别的键上屏「，」，退格就不要；数字后的「.」「:」保持半角。
  • { }：中文状态下默认打成「」（设置里能关），不看引擎的标点表。
  • 忘掉一个词：候选上按 Shift+⌫，告诉打字引擎和个人化组件。

联想

  • 在空格或数字选词、标点、快捷键引擎上屏、选中联想后触发；开不开按应用算：应用设置优先，没设时终端（Terminal、iTerm2、Ghostty、Warp 等十个）默认关，其余跟随全局；个人化组件须在运行。上屏后 0.25 秒内没有按键才发出请求，期间按键即取消。
  • 个人化组件先从最近 5000 段上屏中找用户写过的接续（最多 3 个），再请主控续写（/v1/continue，k=8、6 个 token），首 token 是汉字且概率 ≥ 0.2 才采用，合计最多 5 个。
  • 发出后 1 秒内无答复则放弃；未激活时淡显前 3 个、不放显示串，按键照常交给应用，4 秒后收起；按 Tab 激活后列出全部，数字、空格选，方向键和 Tab 移动，Esc、回车、退格收起；激活后高亮的那个放在光标处当显示串（拼音显示在候选窗里时也一样），免得 Chromium 把 Tab 交给网页。
  • 有的应用（Grok 这类 Electron 应用）在输入法接下 Tab 后自己又插一个制表符：选词时连它一起换掉；收起联想时不去掉。

写入记忆的记录

topic内容data
ime-commit同一应用中连续上屏合成的一段（间隔 > 60 秒、换应用、换了出字的引擎或前文对不上时断段；满 2000 字或停手 20 秒写入；切走时的自动上屏单独一条）app、source、kind、auto、context（前文末 200 字，标为第三方）
ime-correction选了非首选、删掉刚上屏的字选择或删除的明细
ime-forget用户在候选中删除某词input、text
  • 凭证经 mask_secrets 只遮那一串；敏感类别（健康、法律纠纷、宗教、政治）按整段文字计算。
  • 保留期（个人化组件选项 keep，只能改 options.json）可选永久、365、90、30 天，启动时和每 6 小时清理一次，只清 ime-commit、ime-correction，被理解引用的保留。
  • 壳每 15 秒 ping 个人化组件取记忆状态，菜单和设置窗口显示「记录中 / 已暂停 / 当前应用禁止 / 已关闭 / 不可用」；第一次用时在候选窗提示一次在哪里关。
  • 读取：最近 5000 段 ime-commit，用作联想素材。

主控任务

任务端点用途
luoke-ime.rerankPOST /tasks/<task>/v1/score候选打分（按任务参数分批，默认 16 个、前文 2000 字）
luoke-ime.predictPOST /tasks/<task>/v1/continue联想续写

请求超时 2 秒。收到 hello 时对两个任务各预热一次。发布版只经主控打分（选项 scorer 写什么都当 hub）；主控不可用时没有重排，联想只给用户自己写过的接续。

输入法菜单只放常用操作：输入方案、当前中英文模式、清掉学到的词、当前应用（此应用设置、在此应用关闭联想、在此应用禁止记录）、记忆记录状态（开启 / 暂停 / 恢复、管理记忆）、设置、高级（开发模式、打开引擎文件夹、打开设置文件）；引擎停用、沙盒拦截、等确认的第三方引擎也列在这里。

安全

  • 安全输入（IsSecureEventInputEnabled）：不读前文、不写记忆、不打分；一段组字中碰到过安全输入，整段都按安全输入处理。
  • 沙盒：默认拒绝；禁止读取钥匙、凭据、浏览器、邮件等 40 多个路径和整个 ~/.luoke（只放行自己的文件夹）；不许创建符号链接；禁止借助 open、osascript、剪贴板等外发。
  • 拦截上报：每条拒绝带标签，壳读取系统日志，严重的列入菜单。系统日志订阅（log stream）套在一个 sh 里，输入法退出（含被强制结束）时随之结束。

安装与输入源

LuokeIME --register 只注册（macOS 26 起不再请求启用，须用户在系统设置里添加）；--status 输出一行 JSON（state：not_registered / not_added / added_not_selectable / ready，另有 other_copies），供螺壳的首次运行向导和诊断用；--select 切换后另起进程核对，没切过去退出码 3。用户自己打开 LuokeIME.app 而还没添加时弹添加引导，每秒检查，加好后提示去任意输入框试打。

系统要求

螺壳只在 macOS 26 起安装输入法（清单 min_macos 26）；LuokeIME.app 本身的最低系统是 14.0，供手动安装验证旧系统。

已知限制

  • 个人化组件不读记忆中的理解（常用说法等），打分没有个人化。
  • 候选窗不能用鼠标点选；引擎选项没有 A2UI 界面。
  • 快捷键引擎不检查冲突、停用不进菜单。
  • 个人化组件卡死不检测；转问没有限流。
  • 没有打错纠正。
  • 快捷键引擎上屏后的退格不转给个人化组件。
  • 引擎停用、被沙盒拦下只在候选窗提示和菜单里显示，不发系统通知。
  • 收起联想时，应用自己插的制表符留着。
